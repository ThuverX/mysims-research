# Level Bin

<KingdomSpecific />

> Check out the MySims version [here](./LevelXml).

A level is a collection of models, objects and meta data, like grid size.

## Pattern

<Incomplete />
These files have the same instance (group `0`) as the level bin:

| File | Type | Description |
|---|---|---|
| LightSetBin | `0x50002128` | The level's lights |
| Physics | `0xD5988020` | The level's collision. Each base model also has a Physics file with that model's instance |
| BuildableRegionBin | `0xC84ACD30` | The areas the player can build in |

## Pattern

```cpp
import type.base;

struct Vector3 {
    float x;
    float y;
    float z;
};

struct MaterialOverride {
    type::Hex<u64> original;    // material instance used by the model
    type::Hex<u64> replacement; // material instance to use instead
};

struct LevelObject {
    type::Hex<u64> model;   // Win32 Model instance
    Vector3 position;
    Vector3 rotation;       // Euler angles, in degrees
    Vector3 scale;
    u32 overrideCount;
    MaterialOverride overrides[overrideCount];
};

struct LevelBinFile {
    char magic[4];          // LLMF
    u32 version;            // 2
    float startPosX;
    float startPosZ;
    u32 cellSizeX;
    u32 cellSizeZ;
    u32 numCellsX;
    u32 numCellsZ;
    float unknown0;
    float unknown1;
    u32 modelCount;
    u32 objectCount;
    Vector3 boundsMin;
    Vector3 boundsMax;
    type::Hex<u64> models[modelCount];  // base models, drawn at the origin
    LevelObject objects[objectCount];
};

LevelBinFile level @ $;
```

## Unknowns

- The two floats at `0x20` and `0x24`.
- What the start position, cell size and cell count are used for. They match the `GridInfo` fields of the MySims [Level XML](./LevelXml).
- The bounds are often much larger than the area that actually has objects in it.
